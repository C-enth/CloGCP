# ADR-001: Offline modular monolith
Date: 2026-10-09. Status: accepted for foundation, subject to measured validation.

Use Python >=3.11 with Pydantic v2; plan DuckDB, NetworkX, FastAPI and openpyxl.
Use React/TypeScript/Vite/React Flow bundled locally, implemented in later phases.
Prefer PyInstaller onedir; build Windows artifacts on Windows. No external service,
Docker, Electron or microservices. One backend process owns database writes.

This minimizes operational dependencies on a customer laptop and keeps reasoning
independent of transport/UI. Costs: graph memory limits, dependency packaging, local
browser security and Windows-specific validation. Storage and graph performance need
synthetic scale benchmarks before full implementation. See ARCHITECTURE.md for controls.
