# ADR-005: provider-aware offline assessment

Accepted 2026-10-12. Extend the existing modular monolith and DuckDB tables with
additive provider/project metadata. AWS records retain their historical serialization,
identifiers and authorization engine. GCP native evidence uses a separate versioned
manifest translated into the shared source/import contracts. Normalization remains
separate from rules. Findings, decisions, report revisions and exports are shared.

The existing account column remains AWS-only; GCP project identity is explicit.
Enterprise snapshots union both providers and retain their scope denominators.
Provider-specific authorization conclusions cannot be merged. GCP allow bindings are
configuration observations; unresolved inheritance, deny, conditions and boundaries
remain prerequisites. No cross-cloud transition is generated without specific evidence.

No dependency, database, application, runtime cloud client or remote asset is added.
The collection helper is a separate operator-run PowerShell script, never called by
the analyzer. Windows build/runtime and actual collector validation remain independent
acceptance gates.
