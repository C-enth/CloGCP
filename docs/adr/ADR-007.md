# ADR-007: Portable source application replaces the PyInstaller executable

Status: Accepted (0.6.1). Supersedes the delivery decision in ADR-003.

## Context
ADR-003 selected a PyInstaller onedir executable built on Windows. Building it requires a
Windows build host for every release, and it was never executed on Windows. Since 0.5.1 the
same application ships as a portable Python 3.12 source distribution with the compiled
GUI, and 0.6.0 added bundled, hash-locked wheelhouses so that client setup never downloads.

## Decision
CloSec is delivered for macOS (arm64, x86_64) and Windows x64 as one portable ZIP built on
the release machine (`tools/build_wheelhouse.py`, `tools/portable_release.py`). Clients need
only Python 3.12; setup installs bundled wheels with `--no-index --require-hashes`. The
PyInstaller spec, build/smoke scripts, Windows kit tooling and their tests are removed from
the current tree (they remain in Git history). The launcher's frozen-runtime handling is
retained but unused.

## Consequences
One release serves both operating systems and is prepared on macOS. Python 3.12 is a client
prerequisite. Native Windows execution of each release remains a separate acceptance gate;
preparation and hash checks on macOS are not Windows validation.
