# ADR-003: Windows onedir delivery
Date: 2026-10-10. Status: Superseded by ADR-007 (0.6.1); tooling removed from the current tree.

Use PyInstaller onedir with a console launcher, CPython 3.12 x64 and the existing
FastAPI/React/DuckDB services. Compile React before delivery; distribute its local
assets with executable rule metadata. Generated reports need no template workbook.
Exclude private methodology, assessment databases, raw evidence and build environments.

Bundle resources remain read-only. Frozen Windows defaults to LOCALAPPDATA, with an
explicit workspace override. Keep the source launcher default for backwards compatibility.
Use a pinned wheelhouse and hash-enforced offline installation in a clean build environment.
No new storage, security engine or runtime framework. Console startup diagnostics and GUI
shutdown remain available. Windows-specific lifecycle, paths and endpoint-security behavior
require execution on Windows; source tests on macOS do not satisfy that gate.
