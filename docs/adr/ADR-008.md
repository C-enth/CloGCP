# ADR-008: SRE validation is a separate review track; confirmed vulnerabilities need both

Status: Accepted (pilot feedback, phase 2).

## Context
The pilot showed that a configuration finding becomes a vulnerability only after the owning
SRE team checks it against business-as-usual (BAU) configuration. The analyst decision
(CONFIRMED / REJECTED / NEEDS_VALIDATION) records the analyst's technical conclusion and
cannot also hold the SRE outcome without losing one of the two judgements. SRE responses
arrive by e-mail or meeting from per-account workbooks; importing returned spreadsheets was
declined for now in favour of manual recording.

## Decision
- An append-only `sre_validations` table records each SRE verdict per finding:
  SENT_TO_SRE, GAP_CONFIRMED, NO_GAP_BAU (reason required) or NEEDS_INFO, with the SRE
  contact, the recording analyst, a reason and the finding's evidence fingerprint
  (contract `sre-validation-1`). It never changes analyst decisions, report revisions or
  approvals, and it is purged with the finding's scope like analyst decisions.
- A derived stage segregates findings: TRIAGE, REJECTED, WITH_SRE, NO_GAP_BAU,
  SRE_CONFIRMED_GAP, CONFIRMED_VULNERABILITY, SRE_REVALIDATION. The assessor's current
  decision is final: CONFIRMED ("valid") makes a CONFIRMED_VULNERABILITY with or without an
  SRE response, and REJECTED ("not valid", e.g. a known or accepted issue) removes the
  finding from reports filtered by marking. SRE input is optional (revised in 0.8.2 after
  pilot feedback); without an assessor decision the latest current SRE verdict sets the stage,
  and a changed evidence fingerprint moves it to SRE_REVALIDATION.
- The Finalized findings view and its exports contain only CONFIRMED_VULNERABILITY findings.
  Per-account SRE workbooks are generated locally; their verdict columns are not imported.

## Consequences
Confidence, severity, analyst decision and SRE verdict stay independent records. SRE review
never blocks finalization; an SRE-confirmed gap still awaits the assessor's marking. Re-collection that
changes evidence requires a fresh SRE verdict. Importing returned workbooks would need a
separate decision on untrusted spreadsheet input.
